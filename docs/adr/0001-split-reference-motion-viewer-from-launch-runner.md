# Split Reference Motion Viewer From Launch Runner

The reference motion viewer grew from a small command-line script into a module that mixed source loading, robot scene construction, playback, recording, and CLI orchestration. We split reusable source-agnostic reference motion viewing into the motion library, moved concrete command-line orchestration into a launch runner, and kept robot-specific MuJoCo scene application behind a `SceneAdapter` seam. The temporary `mjlab_playground.motion_lib.tools.motion_viewer` compatibility shim is retired; use `mjlab_playground.motion_lib.scripts.launch_motion_viewer` as the canonical command path. This keeps future PyRoki, ProtoMotions, and packaged motion sources producing reference motion clips for the same viewer interface instead of coupling playback to one file format or robot launch path.
